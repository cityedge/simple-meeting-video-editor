# Simple Meeting Video Editor

**v1.0.1 · 会議録画を、見やすく、聞きやすく。**

[English](README.en.md) · [操作マニュアル](USER_GUIDE.md) · [変更履歴](CHANGELOG.md)

Zoomなどの会議MP4から冒頭・末尾・休憩を取り除き、音量を整えて配布用MP4を作るブラウザアプリです。
**標準の「映像無劣化」は元の圧縮映像をそのまま使い、音声だけを処理します。**
低ビットレートの会議録画も、映像の再圧縮による画質低下を避けられます。

日本語・英語のダークUI。動画をサーバーへ送信せず、端末内で処理します。

## はじめる

1. Releasesから **Simple_Meeting_Video_Editor_v1.0.1.zip** をダウンロードします。
2. ZIPを**すべて展開**します。
3. 展開先の `simple-meeting-video-editor/index.html` をデスクトップ版ChromeまたはEdgeで開きます。

インストール、アカウント、APIキー、Node.js、ローカルサーバーは不要です。
`index.html` だけを取り出さず、`lib/`、JavaScript、CSSなどを同じ配置で保存してください。
同じファイル一式をGitHub Pagesに置いても利用できます。起動後の動画処理にインターネット接続は不要です。

## 基本の流れ

1. **MP4を開く**：対応確認と波形の読み込みを待ちます。
2. **不要な区間をカット**：波形をドラッグして範囲を選び、「この区間を削除リストに追加」を押します。時刻入力でも指定できます。
3. **実際に残る区間を確認**：映像無劣化ではキーフレームに合わせて範囲を補正します。
4. **音量を整える**：レベリングと目標ラウドネスを選び、解析後に「補正後を試聴」で確認します。
5. **お試し出力**：確認したい位置へ移動して短いMP4を書き出します。
6. **全体を書き出す**：音声ビットレートを選び、「MP4を書き出す」を押します。

GitHubでは **[日本語の操作マニュアル](USER_GUIDE.md)** をそのまま読めます。
アプリを使っているときは画面下の「使い方」を開いてください。ローカルでは同梱の `USER_GUIDE.html` もブラウザで読めます。
GitHubのファイル一覧からHTMLを開くとソースが表示されるため、リポジトリ内ではMarkdown版をご利用ください。

## 主な機能

- 映像無劣化コピー＋音声処理を標準搭載。任意位置で切る再圧縮モードも選択可能。
- 波形のクリックで移動、ドラッグで削除範囲を選択。拡大表示、先頭・末尾への移動。
- 複数の削除区間を連結編集。指定範囲と実際に残る範囲を表示。
- 小さい会話と大きい挿入動画の音量差をレベリングで緩和し、−14／−13／−12 LUFSを目標に補正。
- 補正前後の波形表示と短い音声試聴。音声自体のモノラル／ステレオは保持。
- 現在位置付近の約30秒お試し出力。全体出力と同じ音量補正を使用。
- 編集設定をJSONに保存・再開。旧Meeting Cutの編集設定も読み込み可能。
- 上部に進捗・中止・保存リンクを固定。左右の編集ペインは一緒にスクロール。
- 再圧縮の映像設定は再圧縮選択時だけ表示。方式を切り替えても設定値を保持。

## 対応範囲と知っておきたいこと

| 項目 | 内容 |
|---|---|
| 対象環境 | デスクトップ版Chrome / Edge。実際のコーデック対応は環境に依存 |
| 入力 | MP4、H.264映像1本、AAC音声最大1本、モノラル／ステレオ、最長2時間 |
| 出力 | MP4。映像コピーまたはH.264再圧縮。音声がある場合はAACへ再圧縮 |
| 無劣化のカット位置 | 残す区間の開始を前・終了を後のキーフレームへ補正。削除範囲が短くなり、短い削除指定が残る場合あり |
| お試し出力 | 無劣化では前後のキーフレームまで広げるため30秒を超える場合あり。再圧縮では現在位置から最大30秒 |
| 音声の確認 | 動画プレビューは元音声。「補正後を試聴」またはお試しMP4で補正音声を確認 |
| 保存 | 対応環境ではファイルへ直接保存。代替のメモリ保存は256 MiBまで |

「映像無劣化」は**映像**についての機能です。音声は自動音量をOFFにしてもAACへ再圧縮されます。
容量表示は目安です。音声ビットレートや残す場面によって元動画との容量比は変わります。
レベリングはノイズ除去ではありません。表示LUFSはAAC圧縮前の測定値で、厳密なTrue Peak上限を保証する処理ではありません。

## 開発者向け

アプリの利用・公開にビルドは不要です。以下は開発時の検証用です。

```sh
npm install
npm test
npm run test:dom
npm run test:integration
```

DOM検証には開発依存のjsdom、統合検証にはFFmpeg/ffprobeが必要です。
[tests/browser-check.html](tests/browser-check.html) は合成動画で実ブラウザのエンコード・保存を確認するページです。
